## D213 — P-SWAPKEEP: the sport chip credits, it never erases

**Finding (measure m1, `tests/measure/v234_rulings/measure_swapkeep_m1.md`, not re-derived).** On every cardio form that offers the picker (429,840 of 622,650, 69.03%), a sport change erases every number typed for the sport left: 96/96 erased, 0/96 restored on return, 48/48 done days end with a blank log. The erasure is the code's stated intent (`index.html:14736`: "a swapped bike never lands on the run chart"). Harness before-picture, HALF_MANNY seed 76308 digest `2d35e8f743680cfa`: `W1 SAT Full Body Support {Long Run} :: Power — explosive first[Kettlebell swing] | Strength[Dips, Inverted rows (rings)]`. The program grid is not the thing that moves here and does not move after.

**Coaching argument.** The log is the athlete's record of what the watch showed, and a watch number cannot be retyped from memory a week later. The picker says "Logged as": it is a crediting decision, not a delete. The old intent is right about credit and wrong about storage, so I keep the first half and drop the second: a swapped bike still never lands on the run chart, and now a left run never lands on it either until the athlete logs the day as a run again. The case this protects is Mario on a Long Run with 45 min and 5 mi already in, tapping Bike to peek or by mistake, then tapping Run. Today both numbers are gone and nothing tells him.

**Semantics.**
1. The active chip is the only credited sport. Its fields sit at the top level of the entry (`run_*`, `bike_mins`, `swim_yards`). Every other sport's top-level fields are `''`. Progress, week MILES, PRs, benchmarks, seeds, ladder and plannedVsLogged all credit the active sport only; `swapFrom`/`swapTo` keep their meaning.
2. On a sport change the leaving sport's field set moves whole (run: `run_dist run_pace run_mins run_reps run_rep_time`; bike: `bike_mins`; swim: `swim_yards`) into one sibling key on the same entry, keyed by sport (I would call it `parked`; the name is the session's siting call). The arriving sport's parked set, if one exists, comes back to top level and into the form. Tapping the already-active chip moves nothing (as today). Symmetric: a bike time typed while swapped parks on the swap back.
3. Nothing erases a parked number except the athlete clearing it in that sport's own form. Parked sets survive Mark Done, reopen, three-hop swaps and the swap back. The swap back shows the planned dose form with the parked numbers on the wheels and the strip restored.
4. **Saved first (Mark Done, then swap):** status stays complete; the swap is a correction of which sport was done, not a new session. The run set parks, the bike face opens on the dash, DONE still counts the day, MILES drops the 5 until the day is logged as a run again. `handleDayStatus` calls `persistLogFields` (its line 7), so Mark Done carries the parked set through the same line the swap does.

**Property the readers must hold.** A top-level sport field is always a credited number. A parked number is read by exactly two things: the form render (`cardioFieldHTML` via `buildLogHTML` and `setCardioSwap`) and the entry carry in `persistLogFields`, sited where `_keepSets` already sits (:14707, the one rebuild). Therefore all eight blind readers stay blind and untouched by construction: `renderWeekView` MILES, `seedFromPriorPrograms` maxDist, `ladderWeekly`, `renderProgressScreen` sums and has-entry, `restMoveCandidates`, the `_hasLog` nudge, `applyRestCardio` (rest days render no picker, so no swapTo), and the :14723 derivation (`doseDerived(null)` returns null at :13465, so no run pace derives while swapped away). The seven swapTo-aware readers stay as they are. `forms-swap-live` (g233:313/:355) holds: no stored log means nothing parked, so the bike face opens on the dash with no strip.

**Does not change.** HALF_MANNY `2d35e8f743680cfa` and every grid (swap state lives only in `ia_logs_`; `buildProgram` never reads it). Dose forms, wheels, strips, `Log the ride`. Key `ia_logs_<pid>`.`w<N>_<day>`, every existing field name, `swapFrom`/`swapTo`. The journal chip. Out of scope: brick days (two sports on one day stay one sport), the rest sheet (P-RESTWHEEL), the journal arrow glyph.
